# Trust Tell ERP - Mobile Shop Management System

A comprehensive ERP system for managing mobile phone and accessories business.

## 📋 Features

### 1. 🔐 Authentication System
- Email & Password Login
- Multi-user support (Admin + 3 Partners)

### 2. 📊 Dashboard
- Daily sales overview
- Daily expenses tracking
- Profit/Loss calculation

### 3. 📱 Inventory Management
- Add/Edit/Delete products
- Stock tracking (Mobile + Accessories)
- IMEI number tracking

### 4. 🛒 Sales System
- Product sales form
- Auto stock deduction
- Cash/Credit/Installment sales

### 5. 💰 Purchase System
- Supplier management
- Purchase tracking

### 6. 👥 Customer Management
- Customer records
- Purchase history

### 7. 🤝 Partnership Management
- Track 3 partners' investment
- Profit sharing based on investment %

### 8. 💸 Daily Expenses
- Track daily expenses

### 9. 📊 Reports Section
- Daily/Monthly sales reports
- Profit reports
- Partner profit sharing report

## 🛠️ Tech Stack
- Frontend: React.js + Tailwind CSS
- Backend: Node.js + Express.js
- Database: MongoDB
